Setup 2 — Cell vs. Gaussian running wave

A single cell at \(\tilde x = 0\) is approached by a Gaussian chemoattractant pulse traveling at nondim speed \(C\) (capital, to avoid clash with the dimensional speed \(c\)). The cell experiences the rising-then-falling cue and gradient as the wave passes. The phenomenon of interest is polarization-induced rectification: a finite net displacement \(\Delta \tilde x \neq 0\) after the wave is gone, even though the spatial gradient integrates to zero. A pure gradient sensor (no polarization inertia) gives \(\Delta \tilde x \approx 0\); the Ginzburg–Landau cell does not, because \(P\) cannot relax instantaneously.

The nondimensionalization is identical to Setup 1 (\(\mathcal{L} = L/L_c\), \(P = p/\sqrt{u/w}\), \(\tilde t = t \cdot r_0 L_c\), \(\lambda\), \(\vartheta\) defined there) plus the wave length \(\sigma\) used to rescale distance: \(\tilde x = x/\sigma\). The cue is

\[ \mathcal{L}(\tilde x, \tilde t) = M\, e^{-(\tilde x - C \tilde t)^2 / 2}, \qquad \partial_{\tilde x} \mathcal{L} = -\mathcal{L}\,(\tilde x - C \tilde t), \]

and the equations of motion become

\[ \frac{dP}{d\tilde t} = \tilde\chi\, \partial_{\tilde x} \mathcal{L} + (\mathcal{L} - 1)\, P + \lambda\,(P^2 - P^4)\, P + \sqrt{2\, \vartheta\, \mathcal{L}}\;\eta(\tilde t), \qquad \frac{d\tilde x}{d\tilde t} = \tilde\mu\, P. \]

Two new wave-related groups and two coupling groups:

\(M = L_{\max} / L_c\) peak cue level relative to threshold \(C = c / (\sigma\, r_0\, L_c)\) nondim wave speed (\(\sigma\) per \(t_0\); the dimensional \(c\) is the wave's physical speed) \(\tilde\chi = \chi / (\sigma\, r_0\, \sqrt{u/w})\) chemotactic coupling \(\tilde\mu = \mu\, \sqrt{u/w} / (\sigma\, r_0\, L_c)\) nondim cell motility

\(\lambda\) and \(\vartheta\) are inherited from Setup 1 unchanged.

Original dimensional equation

From the source spec ginzburg_landay_neutrophils.md:

\[ \frac{dp}{dt} = \chi\, \nabla L + r_0 (L - L_c)\, p + u\, p^3 - w\, p^5 + \sqrt{2\, \theta\, L}\, \xi(t), \qquad \frac{dx}{dt} = \mu\, p, \]

with the running Gaussian \(L(x, t) = L_{\max}\, \exp(-(x - c t)^2 / (2 \sigma^2))\). All nondim groups follow from the rescaling above.

Hill / linear-relaxation alternative model

Selecting the Hill model in the controls replaces the GL polarization SDE with a linear-relaxation form, and the linear velocity \(\tilde\mu P\) with a Hill-saturating response:

\[ \frac{dP}{d\tilde t} = \tilde\chi\,\partial_{\tilde x}\mathcal{L} - P + \sqrt{2\,\vartheta\,\mathcal{L}}\,\eta(\tilde t), \qquad \frac{d\tilde x}{d\tilde t} = \tilde v_{0}\,\frac{|P|^{n}}{1 + |P|^{n}}\,\mathrm{sign}(P). \]

The chemotactic coupling \(\tilde\chi\) and noise strength \(\vartheta\) are shared between models. \(\tilde v_{0}\) and the Hill exponent \(n \in \{1,\ldots,10\}\) replace \(\tilde\mu\); \(\lambda\) has no Hill analog. See ../docs/physics/hill_model.md for the nondimensionalization.

Split the drift into the chemotactic drive \(s = \tilde\chi\,\partial_{\tilde x}\mathcal{L}\) and the autonomous internal response \(f(P,\mathcal{L}) = (\mathcal{L}-1)P + \lambda(P^{3}-P^{5})\). Because \(\partial_{\tilde t}\mathcal{L} = -C\,\partial_{\tilde x}\mathcal{L}\) for a rigid wave, the shifted variable \(q = P + \tilde\chi\mathcal{L}/C\) absorbs the drive and obeys \(\dot q = f\). The singular curve \(\Sigma = \{(\mathcal{L},P) : f(P,\mathcal{L}) = 0\}\) — the instantaneous nullcline of the autonomous response — is drawn in gray on the \(\mathcal{L}\)–\(P\) portrait. For the GL model it factors as \(f = P\,[\mathcal{L} - \mathcal{L}_\Sigma(P)]\) with \(\mathcal{L}_\Sigma(P) = 1 - \lambda P^{2} + \lambda P^{4}\), so \(\Sigma\) is the line \(P = 0\) together with that explicit curve. Crossing \(\Sigma\) flips the sign of \(\dot q\), cutting the cycle into alternating intervals — tinted blue for \(\dot q > 0\) and warm for \(\dot q < 0\). \(\Sigma\) is also exactly where \(U = \tilde\mu P / f\) diverges, which is why the \(q\)–\(U\) panel uses a percentile-clipped \(U\) axis.
