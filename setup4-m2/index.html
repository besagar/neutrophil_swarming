Setup 4b — Self-extinguishing swarm · M2 (per-cell inhibitor)

Same geometry as Setup 4a — a disk of \(N\) neutrophils in a petri dish of nondim radius \(\tilde{R}_{\text{dish}}\) — but each cell now carries an intracellular inhibitor \(R_i\) (per-cell ODE variable, not a diffusing field). The inhibitor accumulates while the cell sees \(\mathcal{L} > \mathcal{L}_r\) and shuts emission off once \(R_i\) crosses an internal threshold. The result is a self-extinguishing wave: it nucleates at the dish centre, propagates outward, then collapses as the wake saturates with \(R_i\).

Reference: Strickland, Pan, Ji, Amir & Weiner (2024) — two-threshold relay model.

Model M2 (per-cell inhibitor). The nondim equations are:

\[ \partial_{\tilde{t}}\mathcal{L} = \tilde{\nabla}^2\mathcal{L} + \frac{1}{\tilde{h}}\sum_i H^-(R_i;\,1;\,n_R)\,H^+(\mathcal{L}_i;\,1;\,n_L)\, \tilde{\delta}^2(\tilde{\mathbf{r}}-\tilde{\mathbf{r}}_i) - \Gamma_L\,\mathcal{L} \qquad \text{(2D–2D)} \] \[ \partial_{\tilde{t}}\mathcal{L} = \tilde{\nabla}^2\mathcal{L} + \tilde{\delta}(\tilde{z})\sum_i H^-(R_i;\,1;\,n_R)\,H^+(\mathcal{L}_i;\,1;\,n_L)\, \tilde{\delta}^2(\tilde{\mathbf{r}}-\tilde{\mathbf{r}}_i) - \Gamma_L\,\mathcal{L} \qquad \text{(2D–3D)} \] \[ \frac{dR_i}{d\tilde{t}} = \tilde{\beta}\,H^+(\mathcal{L}_i;\,\tilde{\mathcal{L}}_r;\,n_{Lr}) - \tilde{\gamma}\,R_i. \]

where \(H^+(x;x_0;n) = x^n/(x_0^n+x^n)\) is the relay gate and \(H^-(x;x_0;n) = 1 - H^+\) is its inhibitory mirror. A cell emits only when its inhibitor is low (\(R_i < 1\), i.e. \(H^-\) close to 1) and the local cue exceeds the relay threshold (\(\mathcal{L} > 1\)). The inhibitor builds up whenever \(\mathcal{L}\) crosses a second, independent threshold \(\tilde{\mathcal{L}}_r\) — typically much smaller than the relay threshold — and decays exponentially with rate \(\tilde{\gamma}\). Absorbing BC: \(\mathcal{L}=0\) at the dish edge.

Key feature. The wave is self-extinguishing: the inhibitor builds up in the wake, shuts off emission behind the front, and the wave eventually collapses. The termination radius is set roughly by the ratio \(\tilde{\beta}/\tilde{\gamma}\) and the threshold \(\tilde{\mathcal{L}}_r\). Unlike M1 the wave does not propagate at the Dieterle speed \(\tilde{c}=\tfrac{2}{\pi}\tilde{\sigma}\); the M2 wave is parameter-sensitive and typically a step-front (disk) rather than a pulse (ring), unless tuned carefully.

Length and time scales. Same intrinsic scales as M1:

\[ \ell_0 = \frac{a}{L_0\,D_L}, \qquad t_0 = \frac{\ell_0^2}{D_L} = \frac{a^2}{L_0^2\,D_L^3}. \]

\(\ell_0\) is the distance at which a single emitter saturates a relay-threshold profile in 3D — the single-cell influence radius. \(R_i\) is normalized to its threshold (\(R_0 \equiv 1\)) so \(R_i \in [0, R_i^{\max}]\) with \(R_i^{\max} \approx \tilde{\beta}/\tilde{\gamma}\) at saturation.

GL cell SDE (Euler–Maruyama). Polarization \(\mathbf{P}_i\) and position \(\tilde{\mathbf{X}}_i\):

\[ d\mathbf{P}_i = \Bigl[ \kappa\,\tilde{\nabla}\mathcal{L} + \lambda\,(\mathcal{L} - \mathcal{L}_c)\,\mathbf{P}_i + \nu\,(|\mathbf{P}_i|^2 - |\mathbf{P}_i|^4)\,\mathbf{P}_i \Bigr]d\tilde{t} + \sqrt{2\,\vartheta\,\mathcal{L}\,d\tilde{t}}\;\boldsymbol{\eta}_i, \] \[ \frac{d\tilde{\mathbf{X}}_i}{d\tilde{t}} = \mu\,\mathbf{P}_i. \]
\(\lambda\)linear activation strength \(\nu\)GL nonlinearity strength \(\kappa\)chemotactic coupling \(\mu\)cell motility \(\vartheta\)noise strength \(\mathcal{L}_c\)cell threshold / relay threshold \(\tilde{\sigma}\)nondim cell density \((= \sigma\,\ell_0^2)\) \(\tilde{h}\)nondim layer height (2D–2D only) \(n_L\)Hill exponent (relay gate) \(n_R\)Hill exponent (inhibition gate) \(n_{Lr}\)Hill exponent (inhibitor production gate) \(\Gamma_L\)LTB4 decay rate \(\tilde{\beta}\)per-cell inhibitor production rate \(\tilde{\gamma}\)per-cell inhibitor decay rate \(\tilde{\mathcal{L}}_r\)second activation threshold (for \(R_i\) ODE) \(\tilde{R}_{\text{target}}\)target radius (nondim, in \(\ell_0\)); cells that reach it stick to it

Initial condition. Unlike M1, no firing source is needed: starting all cells with \(R_i = 0\) is enough — any super-threshold seed (the central cluster) ignites the relay and the wave nucleates spontaneously.

Target — “stick to the target”. A circle of radius \(\tilde{R}_{\text{target}}\) at the dish centre stands for the object the swarm converges on (a candida cluster, a bead, a sterile injury). It is a one-way, absorbing inner boundary: the first time a cell reaches \(\tilde r_i \le \tilde{R}_{\text{target}}\) it is projected onto the circle and frozen there for the rest of the run — it has engaged the target. A stuck cell still polarizes and still emits the cue, so the cue model above is untouched; only \(d\tilde{\mathbf{X}}_i/d\tilde{t} = \mu\mathbf{P}_i\) is suppressed. The target disk is excluded from the initial cell placement, so no cell starts engaged. Switch it off in the controls to recover the plain dish (reflective outer wall only). Engaged cells are ringed in teal on the dish, and the on target KPI is the recruitment curve. See setup4_swarm3d.md §2c.

Interaction paradigm. Set all parameters, press Calculate, then scrub the time slider once the run finishes.

Numerical methods

Identical to Setup 4a: explicit Euler for in-plane diffusion at CFL \(d\tilde{t}_{\text{sub}} \leq \Delta\tilde{x}^2/4\); in 2D–3D an additional Crank–Nicolson step handles \(z\)-diffusion on the non-uniform exponential grid. Per-cell \(R_i\) is integrated with explicit Euler at the host step \(d\tilde{t}\) — \(R_i\) evolves on the slow inhibitor timescale \(1/\tilde{\gamma} \gg d\tilde{t}\), so no sub-stepping is needed. Cell–field coupling uses bilinear PIC.
