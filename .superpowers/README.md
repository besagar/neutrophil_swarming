# .superpowers/

Local-only notes about agent workflows, skill invocations, and any
project-specific Claude Code customizations. Not shipped, not part of the
runtime — purely a place for the user (or Claude) to drop short notes about
"how we work in this repo."

Suggested files (create as needed):

- `skills.md` — which Claude Code skills are useful here (e.g. `/loop` for
  parameter sweeps, `/review` before committing physics changes).
- `playbooks.md` — recurring procedures: "how to add a new setup",
  "how to validate a new integrator", "how to extend the unit system".
- `decisions.md` — short ADR-style notes when a non-obvious technical
  decision is made.
