Ginzburg–Landau model of neutrophil polarization

Three interactive demos of the polarization SDE ∂ₜ p = -∂F/∂p + noise with the 6th-order free energy F = -½ r₀(L-L_c) p² - ¼ u p⁴ + ⅙ w p⁶ - χ p·∇L. All plots are nondimensional; sliders may be exposed dimensionally and feed the nondim parameters via the per-setup linkage.

  • Setup 1 — polarization in a uniform cue (1D and 2D Brownian dynamics in the GL well).
  • Setup 2 — single cell vs. a passing 1D Gaussian wave (chemotactic rectification by polarization lag).
  • Setup 3 — 2D radial swarm with central trap (~1000 cells on a disk; outward Gaussian wave from center; anti-wave regime drives cells inward).
  • Setup 4a — emergent-wave swarm, M1 relay (basic relay model: cells emit LTB4 above threshold; wave speed = Dieterle's \((2/\pi)\tilde{\sigma}\)).
  • Setup 4b — self-extinguishing swarm, M2 (two-threshold model: per-cell intracellular inhibitor \(R_i\) shuts emission off in the wake).
  • Setup 4c — density-sensing swarm, M6.1 (basal-adenosine field \(\mathcal{A}\) shifts the relay threshold \(1\to1+\lambda_A\mathcal{A}\), giving a density-independent wave speed and suppressing channelisation).
  • Setup 4d — quorum-throttled relay, M6.2 (the same basal density signal \(\mathcal{Q}\) instead throttles the LTB4 production rate, \(H^-(\mathcal{Q};1;m)\): flat \(c(\tilde\sigma)\) at \(m=1\), non-monotonic — actively anti-streaming — for \(m>1\)).

Run locally with python -m http.server 8000 from the src/ directory. Source: see ../ginzburg_landay_neutrophils.md and ../docs/PLAN.md.
